WebCodecs API Demonstrations

This page provides links to demonstrations of various features of the WebCodecs API, which allows web applications low-level access to video and audio encoders and decoders.

Demos:

  • Long-Term Reference (LTR) Frames Demo

    Demonstrates the use of manual Long-Term Reference frames in video encoding with WebCodecs. This technique can improve video stream resilience to packet loss. The demo compares a standard encoding setup with one that utilizes LTR frames, simulating network loss and delay.

    WebCodecs Features: VideoEncoder with scalabilityMode: 'manual', encode() options like referenceBuffers and updateBuffer, EncodedVideoChunk, VideoDecoder.

  • Rate Control Demo

    Compares browser internal rate control with an external JavaScript-based rate control algorithm (SimpleRateController) using WebCodecs. Users can adjust target bitrate and other parameters to observe the impact on video quality and stream size.

    WebCodecs Features: VideoEncoder configuration for bitrateMode: 'constant' (internal RC) vs. bitrateMode: 'quantizer' (external RC), dynamic reconfiguration, EncodedVideoChunk metadata.

  • Manual Temporal Scalability Demo

    Illustrates manual temporal scalability using the scalabilityMode: 'manual' feature of WebCodecs with the AV1 codec. The demo encodes a single stream into multiple temporal layers, then decodes and displays different subsets of these layers to show the effect on frame rate and quality.

    WebCodecs Features: VideoEncoder with scalabilityMode: 'manual', av1 encode options, encode() options for buffer management (referenceBuffers, updateBuffer), multiple VideoDecoder instances.
